# Eq. (41): derivation, assumptions, and its steady-state counterpart

Wheelset document §15.4 states that a PINN with unresolved residual R settles at decay rate

  λ* ≈ √(ζ² + (R/2ω)²)                                   (41)

instead of ζ. That claim rests on a single beam run, so this note derives it and states when it should hold.

## 0. Units

λ* is a decay rate in s⁻¹; the beam run gave 5.44 s⁻¹ measured against 6.29 s⁻¹ predicted. So "ζ" in (41) must be the decay rate λ₀ = ζω, not the dimensionless damping ratio. R/2ω must then also be in s⁻¹, which makes R a residual per unit displacement amplitude (units s⁻², the same units as ω²). The consistent form is

  λ*² = λ₀² + (R/2ω)²,  λ₀ = ζω.                          (41′)

## 1. Transient (free decay)

Oscillator: L[x] = ẍ + 2ζωẋ + ω²x = 0, so the exact poles are s* = −λ₀ ± iω_d.

Model of the trained network (assumptions A1–A4):

- **A1.** The network output is a damped sinusoid x̂ = Re[A e^{st}] with s = −λ + iω_d plus an unresolved part. The frequency is correct; only the decay rate λ is free.
- **A2.** The initial condition is enforced, which fixes A.
- **A3.** The unresolved part leaves a residual whose mean square, at every time, is R² times the mean square of the sinusoid. The floor is *relative*: it scales with the local envelope e^{−λt}. It is also uncorrelated with the residual of the sinusoid itself.
- **A4.** The loss is the time average of r² over [0, T] with uniform collocation, and the window holds many cycles.

The residual of the sinusoid is Re[p(s) A e^{st}] with p(s) = s² + 2ζωs + ω². With s = −λ + iω_d, exactly:

  |p(s)|² = (λ−λ₀)² [(λ−λ₀)² + 4ω_d²] ≈ 4ω²(λ−λ₀)²  (small damping, small error).

Averaging over cycles, the loss is proportional to

  J(λ) = [ |p(s)|² + R² ] · g(λ),  g(λ) = ∫₀ᵀ e^{−2λt} dt = (1 − e^{−2λT}) / (2λ).

**Long window (T → ∞):** g = 1/(2λ). Setting dJ/dλ = 0 with |p|² ≈ 4ω²(λ−λ₀)² gives

  8ω²(λ−λ₀)λ − [4ω²(λ−λ₀)² + R²] = 0
  ⇔ 4ω²(λ−λ₀)(λ+λ₀) = R²
  ⇔ **λ*² = λ₀² + (R/2ω)²**,

which is exactly (41′).

**Mechanism.** A relative residual floor is cheaper where the solution is small, so the loss rewards decaying faster. The pull towards the trivial solution x = 0 is balanced by the cost of the pole error, 4ω²(λ−λ₀)².

**Finite window:** minimise J(λ) with the exact g(λ) and exact |p|². This is `predict_lambda_window` in `src/analysis/damping_bias.py`. It approaches (41′) as λ₀T grows.

**MDOF (proportional damping):** apply the same argument per mode, using modal coordinates q_k = φ_kᵀMx and modal residuals φ_kᵀr. Each mode has its own floor R_k and λ_k*² = λ_{k0}² + (R_k/2ω_k)².

**When (41′) should fail:**
- The floor is absolute rather than relative (A3 broken): then decaying faster buys nothing, and the bias vanishes.
- The network isn't near the loss minimum within the damped-sinusoid family: optimisation failure, wrong frequency, or the output isn't one damped sinusoid. "Effective decay rate" is then ill-defined.
- The window is short (use the finite-window form).

## 2. Steady state (forced), the counterpart

Forcing f = Re[F e^{iΩt}] with dynamic stiffness A(Ω) = K − Ω²M + iΩC. Under the same A3 (residual floor R²|X|² relative to the harmonic amplitude), the loss over complex amplitude X is

  J(X) = |A X − F|² + R² |X|²,

which is minimised by the **ridge (Tikhonov) solution**

  X* = (AᴴA + R² I)⁻¹ AᴴF.

For an SDOF at resonance (|A| = 2ζω² with unit mass):

  |X*| / |X| = 1 / (1 + (R/(2ζω²))²).

Reading this as an effective damping ratio gives ζ_eff = ζ[1 + (R/(2ζω²))²]. In decay-rate units:

  λ_eff = λ₀ + R²/(4λ₀ω²)  (ridge, from the peak amplitude).

Compare (41′) expanded for small R: λ* ≈ λ₀ + R²/(8λ₀ω²). The steady-state bias is twice as large at small R, and it grows without bound as λ₀ → 0 rather than tending to R/2ω.

**Conclusion:** Eq. (41) is a transient-decay law and does not transfer to steady-state forced response. The steady-state analogue is ridge shrinkage. This matters here because the paper's method works in steady state, with a fixed harmonic time basis.

**Link to H2.** At resonance the predicted variance ratio is (|X*|/|X|)² ≈ 1 − 2(R/(2ζω²))², i.e. a relative variance error ≈ 2Δζ/ζ with Δζ/ζ = (R/(2ζω²))². This is H2's 2Δζ/ζ, with Δζ given by the ridge law, not by (41).

**With a fixed harmonic time basis** at the true forcing frequency, the time representation is exact, so the time-induced floor is R = 0. Any floor must then come from the spatial or stochastic (gPC-truncation) representation. That is where H1 and H2 meet in the main study.

## 3. Test protocol (P0.4, pre-registered in `experiments/p0_eq41.py`)

- **Transient:** tanh-MLP PINNs on SDOF and 2-DOF free decay.
  - Measure λ by nonlinear least squares on modal coordinates.
  - Measure R as the RMS of [PINN residual − residual of the fitted pole] divided by the RMS of the fitted sinusoid.
  - Compare with (41′) and with its finite-window form.
- **Steady state:** S²-PINN's learnable-frequency Fourier time branch on forced SDOF and 2-DOF.
  - Use a 9-point sweep across resonance and take λ_eff from a modal FRF fit.
  - Compare with (41′), using R at resonance, and with the ridge law.
- **Gate (brief's G0):** median |λ_meas − λ_(41)| / λ_meas ≤ 10% per setting. If it fails, report the measured relation λ² − λ₀² = c (R/2ω)^β and drop any correction built on (41).
