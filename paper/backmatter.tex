\section*{Data availability}
The code that generates every result, table, figure and number in this paper, and the stored result
files, are available at \url{https://github.com/Shreyansh369/wheelset-s2pinn} and archived at Zenodo
(\url{https://doi.org/\ZenodoDOI}). All data are simulated; no measured data were used. The reference rail roughness values of ISO~3095:2013
(Clause~6.2.5, Fig.~2) were taken from their digital transcription in the phonometry library of
J.~M. Requena-Plens (\url{https://github.com/jmrplens/phonometry}, commit af9d770). Code from an earlier,
exploratory phase of the project that is not used in this paper is kept separately in the repository;
no third-party research code is included in the release.
